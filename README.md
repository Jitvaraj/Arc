## 📱 Application Installation & Setup Guide

Orion is a web-based Progressive Web App (PWA). You can install it on any device via your browser.

### 🌐 1. Web Application & PWA (Recommended)
- **Method**: Progressive Web App with ServiceWorker Caching (Fastest, Auto-Updated).
- **Steps**:
  - **Desktop (Chrome / Edge / Brave / Opera)**: Click the **Install** button (📥) in your browser address bar or click **"📲 Instant PWA Install"** inside Orion Settings.
  - **Android (Chrome / Samsung Internet)**: Tap the browser menu (⋮) ➔ Select **"Install App"** or **"Add to Home Screen"**.
  - **iOS (Safari)**: Tap the **Share button** ➔ Select **"Add to Home Screen"**.
  - **Offline Access**: Functions 100% offline after the initial visit.

---

### 🛠️ 2. Building Native Apps (Advanced)

Orion does not currently provide pre-built native binaries. You can easily build them yourself using these tools:

#### 🤖 Android Application (.APK)
- **Method**: Capacitor Native Android Package.
- **Steps**:
  1. Clone this repository.
  2. Run `npm install`.
  3. Run `npx cap add android` (if not already added).
  4. Run `npx cap sync android` to bundle the app.
  5. Run `npx cap open android` to open in Android Studio and build your APK.

#### 💻 Windows Desktop Application
- **Method**: Electron Desktop App.
- **Steps**:
  1. Clone this repository.
  2. Run `npm install`.
  3. Run `npx electron-packager . OrionApp --platform=win32 --arch=x64` to package for Windows.
